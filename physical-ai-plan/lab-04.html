Lab 04 / Week 2–3

SAC, replay and continuous actions

Use a reference SAC implementation as the continuous-control workhorse for later residual policy adaptation.

6 focused hoursReproduce + modifyTheory companion →

The implementation sequence

  1. Trace the actor, two critics, target critics, replay sampling and entropy-temperature update.
  2. Run a small continuous-control benchmark using the repository's documented environment.
  3. Inspect the tanh-Gaussian log-probability and action rescaling. Write one numerical comparison.
  4. Save/reload the actor and normalization state and evaluate on fixed initial states.

How to verify it

  • Target values are detached; replay data and imagined data have explicit provenance.
  • Train/evaluation action conventions match.
  • You can explain the minimum-Q target and diagnose value explosion.

What to produce

A pinned configuration and baseline run with an annotated SAC dataflow diagram.
