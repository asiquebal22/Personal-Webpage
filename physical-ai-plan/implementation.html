03 / Implementation labs

Implementation checklist

Twelve bounded assignments. Implement the essential mechanics yourself; reproduce and modify larger systems instead of rebuilding every framework.

Pretrained-model practice / Weeks 5–7

Work with a VLA and a world foundation model.

The compact coding labs are complemented by two bounded practice blocks: OpenVLA/OFT or openpi inference and adaptation, plus a Cosmos/world-action-model capability audit. These draw from the existing research hours.

Open the hands-on briefs →
Spinning Up belongs here. Use it for conceptual explanations and update equations. Treat its original code as a reference with older dependencies. Use an isolated environment and current documented examples from CleanRL, Gymnasium or Stable-Baselines3 for runnable baselines.

Lab estimates fit inside the weekly ledger. Research-integrated labs use the research allocation as well as coding time; they are not extra hours added on top of the schedule.
