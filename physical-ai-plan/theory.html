Before you start / 90 minutes

A practical self-assessment

Score each area 0–3: 0 unfamiliar; 1 can recognize; 2 can explain/derive; 3 can implement/debug and discuss limitations. Start with the lowest-scoring core areas. Skip a module only after demonstrating its gate.

  • Derive a Bellman target and policy gradient, including a baseline.
  • Trace a PPO/SAC update with tensor dimensions and correct terminal masks.
  • Compose a camera-to-base transform and explain a robot action interface.
  • Compare BC, diffusion/flow policies, VLAs and action-conditioned world models.
  • Explain model-based planning versus persistent policy adaptation.
  • Design an evaluation with held-out layouts, a fair baseline and honest cost accounting.
