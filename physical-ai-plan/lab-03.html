Lab 03 / Week 2

Policy gradients, GAE and a PPO update

Own the update equations; reuse the surrounding training infrastructure.

8 focused hoursImplement + inspectTheory companion →
↓ Starter: ppo_update.pyPython

The implementation sequence

  1. Implement discounted returns and GAE on hand-written trajectories.
  2. Implement clipped policy loss, value loss, entropy and approximate KL with explicit old log-probabilities.
  3. Read CleanRL's PPO file end to end; run one small Gymnasium task and log seeds/configs.
  4. Make one controlled intervention: remove advantage normalization or change the clipping coefficient and explain the effect.

How to verify it

  • Hand-computed advantages match code, including time-limit bootstrapping.
  • No gradient reaches the stored old policy log-probabilities or targets.
  • At least three seeds produce learning curves; a single lucky run is not a claim of convergence.

What to produce

A small original PPO update and an annotated reproducibility report, not a second general-purpose RL library.

Start here

python3 examples/ppo_update.py

The example prints its own teaching checks. Read dependencies and limitations first. A passing teaching example is not a completed research experiment.
