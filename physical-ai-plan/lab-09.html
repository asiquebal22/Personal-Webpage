CEM-MPC as the essential baseline

Test whether the current learned model can solve the obstruction through search before adding policy updates.

6 focused hoursImplementTheory companion →
↓ Starter: cem_planner.pyPython

The implementation sequence

  1. Sample bounded action sequences and score them with the learned dynamics and the same task objective used by adaptation.
  2. Refit elite action mean/variance, execute only the first action or chunk, and reobserve.
  3. Warm-start from the remaining previous plan; log model calls and wall-clock latency.
  4. Compare with random shooting and exact-physics planning as a diagnostic. Label the included 2-D point example as a teaching demo, not a robot benchmark.

How to verify it

  • No future true state leaks into the learned-model planner.
  • Planner and adaptation agent receive the same current observations and comparable compute budgets.
  • Costs, horizon and action limits are saved in the run configuration.

What to produce

A planner baseline and a plot of success versus planning compute.
