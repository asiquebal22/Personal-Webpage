The implementation sequence

  1. Aggregate by held-out layout and training seed; retain raw outcomes.
  2. Plot real success versus correction trials, recovery latency and total model calls.
  3. Report model optimism, success/failure discrimination and nominal-task retention together.
  4. Use layout-level paired bootstrap intervals for method differences. Declare small hardware evaluations preliminary rather than inferring significance from a few episodes.

How to verify it

  • All methods use the same success rubric, reset procedure and evaluation layouts.
  • Hyperparameter tuning and checkpoint selection use development data only.
  • A clean rerun recreates the figures from logged data; example numbers are never presented as experimental results.

What to produce

A reproducible results bundle with ablations, uncertainty and negative cases.
