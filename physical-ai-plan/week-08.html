Week 08 / Evidence

Test generalization and the value of active selection

Determine whether improvement transfers beyond the correction layouts and whether active selection actually beats random selection.

42 core hours
8 h Theory4 h Coding labs23 h Research7 h Interview / career

The daily plan

Day 1 starts on your selected program date; the labels are work sessions, not fixed weekdays. Divide each session using the week’s hour ledger.

DAY 01

Evaluate the fixed methods on unseen blocker positions and orientations. Keep new geometries as a separately labeled harder split if feasible.

DAY 02

Run nested correction budgets with matched checkpoints. Evaluate at each prespecified point without adding test data to training or choosing trial candidates.

DAY 03

Collect independent simulation seeds and layout diversity; use layout-level intervals. Use the assigned ReOI/Fail2Progress deep reads and DreamZero/EVO-WAM surveys to update the evidence and novelty matrix rather than adding an unbounded reading backlog.

DAY 04

Run randomized method-order trials with the same reset rubric. Measure operator time, aborted attempts and contact failures; do not infer broad reliability from a small demo.

DAY 05

Follow up on appropriate conversations and practice robotics/RL questions. Use preliminary results without presenting them as accepted publications.

DAY 06

Compare active against random, imagined against executed improvement, and adaptation against MPC. Select the smallest set of ablations needed to explain the outcome.

DAY 07

Recover or absorb overflow

Keep this day flexible. Optional reading or a delayed run can fit here; do not assume another full mandatory workday.

Decision gate

The core result is stable enough to explain. If active selection is not better, avoid a sample-efficiency claim; investigate calibration, diversity or incorrect candidate scores.
