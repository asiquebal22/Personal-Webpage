The implementation sequence

  1. Generate a fixed candidate pool from the current policy and legal development layouts.
  2. Define a transparent score: predicted success multiplied by outcome disagreement; use a diversity filter so top selections are not duplicates.
  3. Compare with uniform random selection from the same pool. Count selection compute and aborted real attempts.
  4. Add real transitions, update the world model between rounds, then repeat policy adaptation. Keep score weights fixed before final evaluation.

How to verify it

  • Selection never reads actual candidate outcomes before choosing.
  • Active and random conditions start from the same base data and use the same real-trial allowance.
  • Do not use held-out test layouts to tune the acquisition score or stop training.

What to produce

A candidate-ranking example and a nested correction-budget curve.
