Generative robot policies and VLAs

What do diffusion, flow matching and a VLA change about the action distribution?

Core concepts · optional full training8–12 study hoursConnected lab 07 →

What to understand

  • Transformer attention and modality masks; DDPM denoising and conditional flow matching before robot-specific architectures.
  • ACT and Diffusion Policy: action chunks, multimodality, execution horizons and temporal aggregation.
  • RT-1 → RT-2 → Open X-Embodiment/Octo/OpenVLA: scaling robot data, VLM transfer and original discrete action decoding.
  • OpenVLA-OFT and π₀/openpi: continuous action chunks, parallel decoding, flow matching, proprioception and embodiment dependence.
  • LoRA, heads/adapters versus full fine-tuning; data, memory, inference latency and held-out execution. Survey π₀.₅ and GR00T as comparison families.

What to derive or explain

  1. Explain the conditional diffusion noise-prediction loss and its inputs.
  2. Construct a straight-line conditional flow-matching target between noise and demonstrated actions.
  3. Compare supervised BC updates with RL updates for a generative policy; do not assume PPO log-probabilities are trivial to obtain.

Connect it to code

Train the tiny two-route action generator, then complete the six-hour VLA practice in the model landscape: run one supported OpenVLA/OFT or openpi inference path and a small adaptation smoke run if compute permits. Compare all three interfaces. A full benchmark reproduction is optional; record unexecuted GPU steps honestly.
