Week 05 / Method

Implement the dream→update→execute loop

Demonstrate genuine policy parameter adaptation from imagined experience, with a fixed model during each adaptation round.

42 core hours
12 h Theory6 h Coding labs20 h Research4 h Interview / career

The daily plan

Day 1 starts on your selected program date; the labels are work sessions, not fixed weekdays. Divide each session using the week’s hour ledger.

DAY 01

Define residual action bounds, replay mixture, rollout horizon, reward/cost terms and actor/critic update counts. Start every condition from the same base actor checkpoint.

DAY 02

Seed short model rollouts from actual development observations. Store predicted transitions in a separate buffer and tag model version, rollout depth and uncertainty.

DAY 03

Implement the chosen SAC-style update using synthetic transitions and original replay. Check actor weight changes, model freezing and critic targets. Profile a complete update round.

DAY 04

Run the adapted actor in the actual simulator, then hardware if the pipeline is ready. Compare measured success with its imagined estimate and save failure videos.

DAY 05

Evaluate nominal scenes after adaptation and preserve failed/time-capped runs. Allocate four research hours to the VLA practice: trace one OpenVLA/OFT or openpi observation/action interface, run supported inference if compute permits, and save the measured configuration.

DAY 06

Compare no adaptation, MPC and imagined fine-tuning on a small development suite. Write one page explaining whether the bottleneck is model fidelity, exploration, credit assignment or optimizer stability.

DAY 07

Recover or absorb overflow

Keep this day flexible. Optional reading or a delayed run can fit here; do not assume another full mandatory workday.
