Lab 01 / Week 1

A blocked gridworld and Bellman backups

Make the obstruction precise before adding neural networks. Keep the start and goal fixed; change only a wall or passage.

5 focused hoursImplementTheory companion →
↓ Starter: bellman_grid.pyPython

The implementation sequence

  1. Implement deterministic transitions and value iteration with an explicit terminal state.
  2. Evaluate the original policy after adding the wall. Then recompute the policy using the updated dynamics.
  3. Plot or print the original path, blocked attempt and revised path; inspect Bellman residuals.
  4. Explain why this experiment demonstrates replanning rather than learning a missing skill.

How to verify it

  • All transition rows sum to one; the terminal value stays zero.
  • The added wall invalidates the original route while a longer valid route remains.
  • Rerunning with the same input produces the same path and values.

What to produce

A tiny reproducible obstruction example and a short explanation of policy evaluation versus policy improvement.

Start here

python3 examples/bellman_grid.py

The example prints its own teaching checks. Read dependencies and limitations first. A passing teaching example is not a completed research experiment.
