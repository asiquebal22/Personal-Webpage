Lab 10 / Week 5–6

Actual policy fine-tuning inside the model

Demonstrate parameter updates that persist after returning to execution; do not relabel action-sequence search as fine-tuning.

8 focused hoursBuild research loopTheory companion →

The implementation sequence

  1. Snapshot the base actor and start each adaptation comparison from the same checkpoint.
  2. Infer the current model state from recent observations. Generate short imagined rollouts from real/development anchor states.
  3. Freeze dynamics within an adaptation round. Fine-tune a residual actor using synthetic transitions and a documented SAC-style update; retain a mix of original replay for retention.
  4. Evaluate in the actual simulator or robot, then compare predicted improvement with executed improvement. Enforce an update/time budget and keep rollback available.

How to verify it

  • Actor weights change; world-model parameters remain fixed within the round.
  • Real samples, synthetic samples and reused samples have separate counters.
  • Report recovery on both the current blockage and untouched retention tasks.

What to produce

The first dream→update→execute experiment, including one complete failure analysis.
