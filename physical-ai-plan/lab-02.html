Lab 02 / Week 1

Frames, kinematics and an IK controller

Build enough geometric intuition to debug a robot policy's actions instead of treating the controller as a black box.

5 focused hoursImplementTheory companion →
↓ Starter: kinematics.pyPython

The implementation sequence

  1. Implement planar two-link forward kinematics and the analytical Jacobian.
  2. Check the Jacobian against finite differences and run damped least-squares IK.
  3. Compose two homogeneous transforms and verify inverse/composition identities.
  4. Repeat the end-effector reaching example in the chosen simulator and document action units and frames.

How to verify it

  • Jacobian error is below a declared numerical tolerance at nonsingular configurations.
  • IK converges on reachable targets and reports failure for an unreachable target.
  • A positive command moves the end effector in the documented frame.

What to produce

A geometry notebook, numerical checks and a diagram of camera, base, tool and object frames.
