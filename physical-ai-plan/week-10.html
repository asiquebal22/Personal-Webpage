Week 10 / Release

Write the story and package a reproducible result

Turn experiments into a research artifact that can be inspected, rerun and discussed in an interview.

42 core hours

The daily plan

Day 1 starts on your selected program date; the labels are work sessions, not fixed weekdays. Divide each session using the week’s hour ledger.

DAY 01

Draft problem, setting, method and experiments. Lead with the concrete failure and the measured outcome. State observation/model assumptions and the hardware scope.

DAY 02

Create publication-quality figures from logged results. Write failure cases and negative findings alongside successes. Separate simulated, physical and illustrative figures.

DAY 03

Run the core pipeline from a clean environment. Record exact revisions, dependencies, commands, checkpoint provenance and expected output formats.

DAY 04

Record a short synchronized imagination-versus-execution video. Include the blockage, base failure, adaptation time, executed recovery and a representative failure.

DAY 05

Practice the 2-, 10- and 30-minute versions of the project. Solve one ML coding exercise and one robotics system-design question.

DAY 06

Have the draft checked for unsupported claims, data leakage and missing baselines. Prepare the repository and technical report for release when ready.

DAY 07

Recover or absorb overflow

Keep this day flexible. Optional reading or a delayed run can fit here; do not assume another full mandatory workday.
